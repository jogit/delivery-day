# Contributing / Contribuer

Issues and pull requests are welcome (English or French). Les issues et pull requests sont les bienvenues (français ou anglais).

- **Bug or idea:** open an issue using the templates. Never paste tokens, VIN or reservation numbers.
- **Code:** Android Studio (JDK 17), `./gradlew testDebugUnitTest` must pass; CI runs it on every pull request.
- **Tesla API changes:** the app relies on an unofficial API. A report with the failing endpoint and HTTP status (without secrets) is very helpful.
- **Translations:** strings live in `app/src/main/res/values*/strings.xml`.
- **Security:** see [SECURITY.md](SECURITY.md).
